경기기록 시스템 사용법 교육 자료

심판·운영진 브리핑용 요약. 15분 분량. 자세한 화면 설명은 아래 가이드 링크를 함께 띄워 두고 진행합니다.

1. 역할과 휴대폰

기록심
경기마다 휴대폰(입력권)을 잡는 한 사람. 득점·제재·부상·시계·구간을 입력합니다. 한 경기에 입력권은 한 대뿐입니다.
감독관
구장당 1명. 자기 휴대폰으로 같은 경기를 열면 보조 입력 상태가 됩니다. 평소엔 보기만 하고, 기록심이 놓친 제재·부상과 경기 종료·확정을 맡습니다. 시계는 건드리지 않습니다.
주심·부심·점수심
입력하지 않습니다. 주심이 득점을 선언하면 점수심이 배번을 불러 주고 기록심이 입력합니다. 점수심은 종이 스코어를 따로 적어 전반 끝과 경기 끝에 화면과 대조합니다.
운영본부(관리자)
심판 배정·시간표·경기 정보·대진 연결·서명 채우기·부상 양식·결과지 인쇄. 관리자 1명이 상주해야 합니다.
말할 것: "폰은 기록심만 잡습니다. 나머지는 확인하고 말로 전달합니다."

2. 경기 전 (기록심)

경기 찾기
경기 기록 · 운영 → 대회 → 시간표 카드를 두 번 누르면 기록 콘솔이 열립니다. 배정된 경기는 보라색 「내 경기」로 표시됩니다.
경기 전 설정
두 팀이 오늘 입은 옷(1번 옷 / 2번 옷)을 고릅니다. 오더지에서 「착용」으로 정해 둔 옷이 미리 선택돼 있습니다. 옷 색이 비슷하면 경고가 뜹니다. 한 팀을 2번 옷이나 운영조끼로 바꿔 주세요.
운영조끼
2번 옷이 없는 팀은 본부 조끼를 입습니다. 조끼 색은 설정 화면에서 바로 고를 수 있고, 배번은 오더지 명단 순서대로 1번부터 자동으로 붙습니다. 조끼를 그 순서대로 나눠 주세요.
시작
경기 시작 (전반 · 시계 시작). 입력권이 비어 있으면 누르는 사람이 가져갑니다.
오더지가 없는 팀은 선수 카드가 안 나옵니다. 숫자판으로 배번만 입력해 진행하고, 운영본부에 알려 주세요.

3. 경기 중

득점
득점한 선수 카드 → 어시스트 선수 (또는 「어시스트 없음 · 저장」). 두 번 누르면 저장됩니다.
제재
위쪽 제재 → 선수 → 종류(주의·옐로·레드 등) → 사유 → 저장. 옐로 2장·레드는 자동 퇴장 처리됩니다.
부상
위쪽 부상 → 선수 → 「경기 참가 불가 / 중단 후 복귀」 → 부위·발생 경위·조치 내역 → 「현장조치 / 후송」 → 저장. 기록지에는 시각만 남고, 상세는 운영본부의 부상자 기록 양식에 입력한 사람 이름으로 자동 기입됩니다. 경기 참가 불가 부상부터 반드시 입력합니다.
잘못 눌렀을 때
위쪽 되돌리기는 방금 것 하나. 더 전 것은 기록 줄에서 수정합니다. 기록은 지워지지 않고 취소 표시만 남습니다.
작전타임
팀 칸의 작전타임 버튼. 1분 타이머가 돌고 시계는 멈춥니다.
보조 입력 주의
감독관이 기록심과 같은 득점을 7초 안에 또 넣으면 주황색 알림이 뜹니다. 같은 득점이면 알림을 눌러 닫고, 다른 득점이면 「다른 득점 · 기록」.

4. 하프타임과 후반

전반 종료
구간 버튼에서 「하프타임」. 하프타임 시계가 따로 돕니다.
후반 시작
시간이 다 되면 화면이 깜빡이고 진동이 울리지만 후반은 자동으로 시작되지 않습니다. 「재개 · 후반 시작」을 눌러야 시계가 돕니다. 코트 체인지는 「코트」 버튼.
기본 시간
전·후반 10분, 하프타임 5분, 연장 5분, 주전 7명이 기본값입니다. 대회 요강과 다르면 경기 전 설정에서 바꿉니다.

5. 경기 종료 · 확정 · 서명

누가
감독관이 합니다. 자기 휴대폰의 경기 종료 (감독관)을 누르면 됩니다. 기록심 폰을 빌릴 필요가 없습니다. 감독관이 배정되지 않은 경기만 기록심이 종료합니다.
종료 화면
페어플레이 점수, 지도자 점수, 최우수선수(팀마다 1명, 안 해도 됨) → 서명 확인 → 경기 종료 · 확정.
서명
마이페이지 등록 서명이 자동으로 들어갑니다. 운영진이 심판 배정을 적용할 때 미리 채워집니다. 「등록 서명 없음」은 운영본부의 「현장 서명」에서 한 번 받으면 그 사람 경기 전부에 들어갑니다.
기록지
확정 뒤 기록지 보기 · 인쇄. 타임라인과 진흥회 양식(제출용) 두 가지입니다.
확정 뒤 정정은 그 경기 감독관과 대회 심판위원장만 할 수 있습니다. 기록심·사무국은 못 합니다. 「정정」을 누르면 사유를 적고 잠금이 풀립니다.

6. 현장에서 자주 막히는 것

증상원인과 조치
갑자기 입력이 안 되고 「보기 전용」이 됨휴대폰이 잠들어 90초 넘게 신호가 끊기면 다른 폰이 입력권을 가져갈 수 있습니다. 「넘겨받기」 한 번. 경기 중에는 화면 자동 잠금을 꺼 두세요.
「다른 화면이 입력 중입니다」두 사람이 같은 경기를 입력하려는 상태. 기록심이 아닌 쪽이 「보기 전용」으로 두거나, 감독관이면 보조 입력으로 그대로 씁니다.
심판이 안 왔거나 바뀜기록 콘솔 위 심판진 줄의 심판진 교체(감독관·심판위원장·운영진). 같은 구장 조 사람이 먼저 보입니다. 바꾸면 서명과 기록 권한도 옮겨집니다.
선수 배번이 다름첫 경기 전이면 선생님이 오더지에서 수정. 시작 뒤에는 심판이 팀 칸의 「오더지」에서 경기복·조끼만 수정할 수 있고, 배번은 운영본부에서 수정합니다.
인터넷이 끊김기록은 휴대폰에 쌓였다가 연결되면 자동 전송됩니다. 화면에 「미전송 N건」이 보이면 그대로 두고 진행하세요. 넘겨받기는 전송이 끝난 뒤에만.
결과지에 선생님 서명이 없음운영본부 「현장 서명」 목록에 그 선생님이 뜹니다. 한 번 받으면 끝난 경기 결과지에도 들어갑니다.

7. 선생님께 당일 아침 한 번 더

  • 첫 경기가 시작되면 오더지를 더 고칠 수 없습니다. 배번이 바뀌면 심판이나 운영본부에 말씀하세요.
  • 2번 유니폼이나 조끼가 없는 팀은 오더지에서 「2번 유니폼·조끼 없음」을 눌러 두세요. 본부 조끼를 빌려 드립니다.
  • 오더지에서 고른 「착용」 옷을 입고 구장으로 오세요. 바꿔 입었으면 심판에게 알려 주세요.
  • 마이페이지 서명이 없으면 결과지 서명란이 빕니다. 운영본부에서 현장 서명을 받습니다.
  • 경기장 밖 질서·쓰레기·응원 매너도 학교별로 평가됩니다.

8. 운영본부 체크리스트

전날
  • 심판 배정 → 미리보기 → 적용 (구장마다 감독관 1명, 1조·2조 각 주심·부심·부심·점수심·기록심)
  • 서명 현황 → 「배정 경기에 서명 채우기」 → 「계정 없음」 인원 확인(이름만 확정된 사람은 로그인·기록·서명이 안 됨)
  • 오더지 탭 → 「표기 통일(전체)」 → 「점검 요약」으로 미연결 팀·오더지 미제출 팀 확인 → 선생님께 독촉
  • 경기 시간(전·후반·하프타임) 기본값이 요강과 맞는지 확인
  • 본부 조끼 세트(1~12번) 색별 2벌 이상, 프린터, 보조 배터리
당일 아침
  • 「현장 서명」으로 서명 없는 심판·선생님 서명 받기
  • 심판 결근 확인 → 심판진 교체
  • 심판에게: 폰 자동 잠금 끄기, 기록심만 입력, 감독관이 종료
1일차 저녁
  • 마지막 경기 확정 → 순위표 확인 → 동점으로 「추첨 필요」가 있으면 현장 추첨 후 결과 입력
  • 본선 자리 채우기 → 2일차 시간표 확인 → 2일차 심판 배정(「1일차 배치 그대로 가져오기」)
대회 후
  • 「부상자 기록 양식 PDF」 내려받아 모니터링단에 제출 (부상 저장 때마다 자동 기입, 작성자는 건마다)
  • 결과지 일괄 인쇄, 대회 종료 처리(입상·경력 반영)
