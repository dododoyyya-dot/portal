1

대회 전날 준비5분

  1. 홈페이지에 본인 아이디로 로그인되는지 확인합니다. 비밀번호를 잊었으면 로그인 화면 아래 재설정 메일 받기.
  2. 서명 등록: 마이페이지 ✍ 화면에 바로 서명하기 → 손가락으로 서명 → 저장. 경기 종료 때 결과지에 자동으로 들어갑니다.
  3. 메뉴 대회 → 경기 기록 · 운영에서 축전이 「🧑‍⚖️ 내 심판 업무」로 보이는지, 대회 화면 위에 「내 권한: 경기 기록·종료」 또는 「내 권한: 팀 평가」가 보이는지 확인합니다.
  4. 휴대폰·태블릿 충전, 화면 밝기 최대, 화면 자동 꺼짐 시간을 길게.
✍ 서명 등록경기 기록 · 내 권한 확인
2

내 경기 찾기

  1. 🗓 대진 · 시간표 탭에서 날짜 탭(1일차 예선 · 2일차 본선)을 고르면 시각 × 구장 표가 나옵니다.
  2. 보라색 테두리 카드가 내가 배정된 경기입니다(「🙋 내 경기 · 주심」처럼 임무 표시). 시간표 위 보라색 줄에 내 경기가 시간순으로 모여 있고, 누르면 바로 열립니다. 🙋 내 경기만 보기도 있습니다.
  3. 다른 경기는 카드를 두 번 누르면(휴대폰은 두 번 탭) 기록 화면이 열립니다. 🏁 경기 탭 목록에서 열어도 됩니다.
🗓 시간표 열기🏁 경기 목록
3

경기 기록 순서기록 화면 하나로 끝납니다

  1. 입력 시작스코어 입력은 보통 그 경기 점수원이 합니다. 위쪽 줄에 「입력권이 비어 있습니다」가 보이면 입력 시작. 한 경기는 한 기기에서만 입력합니다. 다른 사람이 입력 중이면 「○○ 입력 중 — 보기 전용」, 맡기로 했으면 넘겨받기.
  2. 경기 시작 설정① 오늘 입은 경기복 — 오더지에서 「착용」으로 고른 옷이 미리 선택돼 있습니다. 현장에서 다르면 바꿉니다(배번도 그 옷 기준으로). ② 구간 시간 — 전·후반 10분·하프타임 5분·연장이 기본. → 이 설정으로 기록 화면 열기
  3. 선수 명단 확인팀 칸에 오더지 선수 전원이 배번 순서로 나옵니다(PC 한 줄 6명 · 휴대폰 4명). 주전·후보 구분과 교체 기록은 없습니다. 팀 칸 오른쪽 위 오더지로 배번·경기복을 바로 고칠 수 있습니다(운영진·대표자).
  4. 경기 시작 · 풀아래 ▶ 경기 시작 → 전반과 시계가 시작됩니다. 첫 스로우 팀의 전반 풀을 누르면 상대 팀에 「후반 풀」이 자동 표시.
  5. 득점위 줄 오른쪽 🥏 득점(기본 상태)이나 큰 점수 숫자를 누르면 선수 명단으로 내려갑니다 → 득점 선수 → 어시스트 선수(없으면 어시스트 없음) → 저장되고 점수판으로 돌아옵니다. 누가 넣었는지 놓쳤으면 득점자 모름 — 점수만 올리기 후 나중에 「수정」.
  6. 제재(주의·옐로·레드)위 줄 오른쪽 🟨 제재 → 선수(또는 👔 지도자 제재) → 주의·옐로·레드 → 사유 → 저장하면 점수판으로 돌아오고 다시 득점 상태. 레드·옐로 2장은 「퇴장」으로 잠깁니다(그 경기만).
  7. 작전타임점수 아래 작전타임 → 경기 시계가 멈추고 1분 타이머. 구간마다 팀당 1번.
  8. 하프타임 · 후반 · 연장시계 위 「전반전」 옆 ▶ → 하프타임 5분 타이머. 끝나도 자동으로 넘어가지 않으니 재개. 팀 위치를 바꿀 땐 시계 옆 ⇄ 코트(점수판과 아래 기록이 함께 좌우로 바뀜).
  9. 잘못 눌렀을 때방금 것은 위쪽 줄 ↩ 되돌리기. 이전 기록은 아래 기록 줄의 수정(선수·시간 초 단위) 또는 취소. 시계는 시계를 눌러 ±1초·±10초·±1분·직접 입력, 리셋은 이 구간 0:00.
💡 기록은 저장 즉시 홈페이지 첫 화면의 구장별 실시간 스코어와 라이브 중계 화면에 그대로 나옵니다. 따로 입력할 곳은 없습니다.
4

경기 종료감독관(감독관이 없는 경기는 주심·기록원)

  1. 아래 경기 종료. 흐리게 「경기 종료 (감독관)」으로 보이면 감독관을 불러 주세요.
  2. 페어플레이 가점(팀마다)
    +5+4+3+2+10−1−2−3
    지도자 가점도 같은 5 ~ −3.
  3. 최우수선수를 팀마다 1명(뽑지 않아도 됨).
  4. 경기 종료 · 확정 → 서명이 자동으로 들어가고 타임라인 기록지가 바로 열립니다. 위쪽 진흥회 양식(제출용)으로 바꿔 🖨 인쇄 · PDF 저장.
⚠ 확정된 경기는 심판 계정으로 고칠 수 없습니다. 잘못을 발견하면 운영진에게 「정정」을 요청하세요. 본선은 이긴 팀이 다음 경기에 자동으로 올라갑니다.
5

팀·학교 평가확정 심판 전원 · 경기 밖 질서와 선행

  1. 대회 화면 ⭐ 팀·학교 평가 탭 → 부문 → 팀 → 사유 → 점수(−3 ~ +3) → 내용 → 기록하기.
  2. 감점 사유: 다툼·폭언 · 쓰레기·청결 · 응원·학부모 질서 · 시간·집합 미준수 · 비교육적 행동 / 가점 사유: 선행·봉사 · 모범 응원·매너
  3. 내용에는 장소·시각을 짧게(예: 3구장 응원석 쓰레기 방치, 11:40). 본인 기록은 그 팀을 펼쳐 취소할 수 있습니다.
⭐ 팀·학교 평가 열기
🛠

운영진 · 심판위원장 전용필요할 때만

  1. ① 구장 카드 채우기시간표 위 🧑‍⚖️ 심판 배정 → 날짜 탭을 고르면 구장마다 카드가 나옵니다. 감독관 → 기록원 → 1조(주심·부심·부심·점수심) → 2조 순서로 칸을 누르고 오른쪽 후보 패널에서 이름을 고르면 다음 빈칸으로 넘어갑니다. 후보 줄에는 신청 직무·자격 급수·주심/심판 경력이 보이고, 이름 검색도 됩니다. 같은 날 한 사람은 한 자리만 — 이미 배정된 사람은 흐리게 막히고 눌러도 들어가지 않습니다. 고를 때마다 자동 저장.
  2. ② 미리보기 · 적용둘째 날이 같으면 N일차 배치 그대로 가져오기. 👀 미리보기(구장 경기에 1조 → 2조 → 1조… 시간순으로 번갈아, 경기별로 바꿀 수 있음) → ✅ 적용. 이미 끝난 경기는 건너뜁니다.
  3. 경기 정보의 심판진경기 ✏️ 설정 → 맨 위 1구장 A조 적용 버튼으로 한 번에 채웁니다(「이 경기 차례」 표시가 그 경기 순번의 조). 한 명씩 고칠 땐 이름 칸을 누르면 그 임무 확정자 목록, 글자를 치면 검색 — 누르거나 정확히 치면 초록으로 적용.
  4. 서명 현황위쪽 ✍ 서명 현황 → 심판진 등록 서명, 팀 대표자 등록 서명·오더지 서명 기입 여부. 없는 사람에게 🔔 등록 요청 알림.
  5. 시간표 옮기기🔒 시간표 잠김 · 눌러서 편집 → 카드를 끌거나 ✎ 로 날짜·시각·구장을 직접 고칩니다. 다 했으면 다시 잠급니다.
  6. 오더지 없는 팀📝 오더지 탭 → 「대진표 팀 ↔ 참가 신청 연결」을 펼쳐 ✍ 오더지 직접 입력. 감독교사 서명은 오더지에서 ✍ 감독교사 현장 서명 받기(그 오더지에만 저장).
  7. 시험 기록 지우기기록 화면 위 🧹 초기화 — 「초기화」라고 입력하면 그 경기를 경기 전으로 되돌립니다(실제 경기에는 쓰지 마세요).
  8. 확정 경기 정정기록 화면 아래 정정 → 사유 입력 → 잠금 해제 후 고치고 다시 확정.

이럴 땐

「내 심판 업무」나 「내 권한」이 안 보여요

심판 모집에서 확정된 임무가 감독관·주심·점수원·기록원·심판위원장이면 기록 권한, 부심이면 평가 권한입니다. 확정이 늦게 바뀌었으면 운영진이 경기 기록 화면을 한 번 열면 명단이 맞춰집니다. 안 되면 운영본부에 이름을 알려 주세요.

보라색 「내 경기」 표시가 안 보여요

운영진이 심판 배정을 아직 넣지 않았거나 다른 이름으로 들어간 경우입니다. 권한은 그대로 있으니 카드를 두 번 눌러 기록하면 됩니다.

인터넷이 끊겼어요

기록은 계속 입력하세요. 위쪽 줄에 「미전송 N건」이 보이고 연결되면 자동으로 보내집니다. 전송이 끝나기 전에는 화면을 닫거나 다른 기기로 넘기지 마세요.

다른 기기에서 입력 중이라고 떠요

같은 경기를 다른 사람이 열어 두었습니다. 맡기로 했으면 「넘겨받기」를 누릅니다.

선수 배번이 현장과 달라요

경기복을 바꿔 입었으면 시작 설정 ① 경기복에서 옷을 바꿉니다. 배번 자체가 다르면 팀 칸 오른쪽 위 「오더지」에서 고치거나 운영진에게 알립니다.

오더지가 없는 팀이에요

시작 설정에 「오더지 없음」이 표시되고, 득점할 때 숫자판으로 배번을 입력합니다. 운영진이 「오더지 직접 입력」을 하면 선수 카드가 바로 생깁니다.

잘못 확정했어요

운영진에게 경기번호와 내용을 알려 주세요. 「정정」으로 잠금을 풀고 고칩니다.
